02 / Your next session

Set it up. Then just launch.

A FAT32 SD card, your homebrew files, and a short list telling Blizzard where to find them.

Using the Homebrew Channel

  1. Copy the app to your SD card.Once available, extract the app ZIP to the SD card root. Keep boot.dol and meta.xml together in apps/Blizzard/.
  2. Add your payloads.Place every payload file and folder inside sd:/payloads/. The example files listed in the XML are not bundled homebrew.
  3. Edit the list.Give each payload a name and a path in sd:/payloads/payloads.xml. Restart Blizzard after changing the file.
  4. Launch Blizzard.Open it in the Homebrew Channel. Use Up/Down to select, A to launch, and HOME to exit the loader.
SD CARD / EXAMPLE LAYOUT
  • sd:/
  • apps/Blizzard/
  • boot.dol
  • meta.xml
  • payloads/
  • payloads.xml
  • example/boot.dol
  • tools/demo.elf
Payload paths are relative to sd:/payloads/.
Using the standalone payload instead?

Extract its release ZIP to the SD card root, keeping Blizzard as sd:/boot.dol and its configuration in sd:/payloads/. Use your existing compatible exploit setup. LetterBomb tries boot.elf first, then boot.dol, so an existing root-level boot.elf will take priority. Back up existing files before replacing them. The Blizzard ZIP does not include the console-specific LetterBomb files or the HackMii Installer. See LetterBomb’s documentation.

04 / Good to know

Before you press A.

Are the app and payload different programs?

No. Both packages contain the same Blizzard executable. The app package puts it in the Homebrew Channel’s app directory; the standalone package puts it at the SD root for a compatible exploit to launch.

Does this install a channel on the Wii Menu?

No. The app appears inside the Homebrew Channel. Blizzard does not include a WAD, a forwarder channel, or a Homebrew Channel installer.

Which files can Blizzard load?

DOL files and static 32-bit big-endian PowerPC ELF executables up to 8 MiB. The ELF’s expanded loadable segments plus its internal header must also fit within 8 MiB. Dynamic ELF executables, payload arguments, and USB loading are not supported. Some valid Wii homebrew uses memory layouts that Blizzard does not currently support.

Why isn’t my payload appearing or launching?

Check that its name and relative path are in sd:/payloads/payloads.xml, and that the file exists at that path. Use forward slashes and the documented self-closing entry format. XML comments and numeric entities are not supported. Restart Blizzard after edits. The loader reports file and executable validation errors in its menu.

Can I return to Blizzard after launching a payload?

Returning directly to Blizzard is not implemented. Each launched application handles its own exit behavior. Run only payloads you trust, and check their own resource and setup requirements.
