Blizzard

An XML-driven launcher for DOL and ELF homebrew. Keep your payloads in sd:/payloads/ and choose what to boot from a colored, controller-driven menu.

SOURCE AVAILABLEEARLY DEVELOPMENT

Source and example configuration are ready to download. See the project page for Homebrew Channel app and standalone payload release availability.

Downloads & setup ↗Source ZIP ↓

App or standalone payload?

Both are the same Blizzard loader with different SD card layouts. The app opens inside an already-installed Homebrew Channel, so you don’t need to trigger LetterBomb for every session. Blizzard does not install a Wii Menu channel.
